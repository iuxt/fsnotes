# Git 变更界面

运行 `bash Tests/GitChanges/run.sh`，默认使用 `.build/SourcePackages/checkouts/swift-cgit2/libgit2`。
也可用第一个参数指定项目锁定版本的 libgit2 源码目录。

测试直接编译生产 Git 状态、差异、暂存、取消暂存、提交代码和 HTML 渲染器，在临时仓库中验证：

- 无提交的仓库、分离 HEAD、新增文件、删除、重命名。
- 同一文件同时存在已暂存和未暂存修改，分别对比 HEAD／暂存区／工作目录。
- 只提交暂存区，取消暂存时保留工作目录内容和其他已暂存文件。
- 忽略文件、回收站、二进制文件、冲突、过期文件状态、空提交。
- 行号、HTML 转义和大文件预览上限。
- `notes/` 目录内相同长度的原子保存，以及最近提交信息。

应用入口：左侧栏「无标签」与「回收站」之间的「Git 变更」按钮。
点击后直接切换主窗口内容：中间显示并排／统一差异，右侧筛选文件、逐文件或批量暂存／取消暂存和提交。
笔记保存和文件系统事件触发刷新，打开时等待保存队列完成；空状态显示最近提交信息。
输入提交说明后使用「提交已暂存变更」，或按 ⌘↩。⌘R 刷新。
「推送」发送已有提交；「同步」沿用应用的拉取、提交全部本地变更、推送流程。
